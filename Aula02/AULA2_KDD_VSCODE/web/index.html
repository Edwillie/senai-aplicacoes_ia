02 | PREPARAÇÃO

Vamos colocar o projeto para funcionar

Vamos preparar o ambiente de forma reproduzível. O ponto mais importante é garantir que o Python usado no terminal seja o Python do .venv.

1

Conferir o Python

Criar o ambiente virtual

O ambiente virtual mantém as bibliotecas deste projeto isoladas.

CLIQUE EM UMA CÉLULA

Vamos interpretar a matriz

Cada célula representa uma combinação entre o que realmente aconteceu e o que o modelo previu.

FALSO POSITIVO

Conforme → Retrabalho

Uma peça boa poderia ser enviada para retrabalho ou inspeção adicional.

  • custo adicional
  • perda de tempo
  • retrabalho desnecessário
FALSO NEGATIVO

Retrabalho → Conforme

Uma peça que precisava de correção poderia seguir adiante como se estivesse conforme.

  • problema não tratado
  • risco de propagação no processo
  • impacto potencialmente maior
